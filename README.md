# MongoDB Commands

This project contains MongoDB command files that demonstrate various database operations.

## Requirements
- MongoDB version 4.4
- Ubuntu 20.04 LTS

## Files
- `0-list_databases`: Lists all databases
- `1-use_or_create_database`: Uses or creates a database
- `2-insert`: Inserts documents into a collection
- `3-all`: Lists all documents in a collection
- `4-match`: Finds documents matching specific criteria
- `5-count`: Counts documents in a collection
- `6-update`: Updates documents in a collection
- `7-delete`: Deletes documents from a collection
- `8-update_many`: Updates multiple documents in a collection

## Usage
Each file contains MongoDB commands that can be executed using the MongoDB shell
